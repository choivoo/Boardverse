- Used for: optional analysis of *finished* chess games, executed in a Web Worker on the viewer's device (`/engine/*`).
- Files shipped in `dist/engine/`: `stockfish-19-lite-single.js`, `stockfish-19-lite-single.wasm`, `COPYING.txt` (full licence text).
  They are copied from the npm package `stockfish@19.0.0` at build time (`scripts/copy-engine.mjs`); they are not committed to this repository.

- Corresponding source: https://github.com/nmrugg/stockfish.js (tag v19.0.0) and https://github.com/official-stockfish/Stockfish

## Opening names — lichess-org/chess-openings
- Used for: the opening dictionary (`src/openingsData.json`, generated by `scripts/buildOpenings.ts`).
- Source: https://github.com/lichess-org/chess-openings (files `a.tsv`…`e.tsv`), fetched 2026-10-06 (commit SHA could not be retrieved in the build environment).
- Licence: public domain / CC0 1.0 — the repository README ("Copyright" section) states the data set is in the public domain and released under CC0.
