## Opening names — lichess-org/chess-openings
- Used for: the opening dictionary (`src/openingsData.json`, generated by `scripts/buildOpenings.ts`).
- Source: https://github.com/lichess-org/chess-openings (files `a.tsv`…`e.tsv`) at commit `65bb03f76c7f077984db01a2f2d0534e4181ddfe` (the `master` head on 2026-10-06; verified to have byte-identical TSVs to those the data was originally generated from). SHA-256 of each input file is stored in `src/openingsData.json` (`source.files`).
- Regenerate: `node scripts/fetch-openings.mjs <sha> <dir>` then `npx tsx scripts/buildOpenings.ts <dir> <sha> <YYYY-MM-DD>` (deterministic: identical inputs give a byte-identical file; the committed file can be used without any download).
- Licence: public domain / CC0 1.0 — the repository README ("Copyright" section) states the data set is in the public domain and released under CC0.
- Only names, ECO codes and move sequences are used. There are no game counts or win rates.
