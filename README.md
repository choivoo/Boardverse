# Boardverse 1.0

체스와 오목을 즐기는 클라이언트 전용 보드게임 플랫폼 (React + TypeScript + Vite).

## 실행
```
npm install
npm run dev        # 개발 서버
npm run build      # 타입 검사 + 프로덕션 빌드
npm test           # 규칙 단위 테스트 (vitest)
npm run preview    # 빌드 미리보기(4173). 다른 터미널에서: node scripts/e2e.mjs (Chromium 필요, $CHROMIUM로 경로 지정)
```
환경변수는 필요하지 않습니다 (`.env.example` 참고).

## 기능
- 체스: [chess.js](https://github.com/jhlywa/chess.js)(BSD-2) 규칙 엔진 — 캐슬링, 앙파상, 승격, 체크/체크메이트/스테일메이트, 기물 부족·3회 반복·50수 무승부. 체스 시계(무제한/5분/10분/15+10), 시간 초과 패배, 되돌리기, 기권.
- 오목: 자체 규칙 모듈(`src/games/gomoku.ts`), 13/15/19 판, 프리스타일(5목 이상 승리, **금수 없음**), 무승부, 되돌리기.
- 컴퓨터 상대(초급/보통/어려움; 간단한 휴리스틱 봇, 강한 엔진 아님)와 같은 기기 2인.
- 게스트 전용. 최근 게임 기록은 브라우저 localStorage에만 저장(최대 50개, 홈에서 삭제 가능).
- 키보드(방향키+Enter), 스크린리더 라벨, 색 외 표시(기호/테두리), 반응형, 다크 모드.

## 제한 사항 (1.0 미포함)
- 계정/로그인, 서버 저장, 온라인 대국·방 초대·관전, 친구, 랭킹, 퍼즐은 **구현되지 않음** (백엔드 필요). 규칙 모듈은 UI와 분리되어 있어 서버 검증을 붙일 수 있는 구조입니다.
- 진행 중 대국은 새로고침 시 사라집니다. 체스 시계는 클라이언트 시간 기준(로컬 대국 한정).
- 이미지 생성 도구는 사용하지 않았습니다. 로고는 직접 만든 SVG, 기물은 유니코드 글리프입니다.
- 모바일은 Chromium 375px 뷰포트 스모크 테스트로만 확인했고 실기기 터치는 미검증입니다. ESLint는 설정하지 않았습니다.
