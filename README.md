# Boardverse 1.0

체스와 오목을 즐기는 클라이언트 전용 보드게임 플랫폼 (React + TypeScript + Vite).

## 실행
```
npm install
npm run dev            # 클라이언트 개발 서버(5173). 온라인 대국까지 쓰려면 다른 터미널에서 npm start
npm run serve          # 빌드 후 서버 실행: 정적 사이트 + 온라인 대국(WebSocket /ws), 기본 포트 8787 ($PORT)
npm test               # 규칙·서버 단위 테스트 (vitest, 27개)
node scripts/e2e.mjs   # npm run serve 실행 중에 Chromium으로 모바일 E2E (CHROMIUM 경로, SHOTS=폴더로 스크린샷)
```
환경변수는 `PORT`(선택)뿐입니다 (`.env.example`).

## 배포 (직접 하셔야 합니다)
이 저장소는 배포를 수행하지 않았습니다. 서버는 정적 파일과 WebSocket을 같은 포트로 제공하는 Node 앱 하나입니다. `Dockerfile`이 있어 Node를 돌릴 수 있는 곳(Fly.io, Render, Railway, VPS 등)이면 `docker build` 후 그대로 실행됩니다. 반드시 **HTTPS(wss)** 로 서비스하세요(PWA 설치·서비스워커는 HTTPS 필요). 정적 호스팅(GitHub Pages 등)만 쓰면 로컬 플레이만 되고 온라인 대국은 서버가 없어 동작하지 않습니다. 인스턴스를 여러 개 띄우면 방이 메모리에 있어 서로 공유되지 않으므로 1개로 운영하세요.

## 기능
- **모바일 우선(갤럭시 Z 폴드 계열 기준)**: 커버 화면(~360px 폭)은 세로 한 열, 하단 고정 버튼; 펼친 화면(near-square)은 판 왼쪽·컨트롤 오른쪽; 접고 펴도 대국 상태 유지; 터치 목표 48px, 안전 영역/동적 뷰포트 대응. PWA(홈 화면 설치, 오프라인 로컬 플레이).
- 체스: [chess.js](https://github.com/jhlywa/chess.js)(BSD-2) — 캐슬링, 앙파상, 승격, 체크메이트/스테일메이트, 기물 부족·3회 반복·50수 무승부, 시계(무제한/5/10/15+10), 되돌리기(로컬), 기권.
- 오목: 자체 규칙 모듈, 13/15/19 판, 프리스타일(5목 이상, **금수 없음**). 터치 기기에서는 "탭 → 미리보기 → 착수 확정"(끌 수 있음)으로 오탭 방지.
- 컴퓨터 상대(초급/보통/어려움; 간단한 휴리스틱 봇) · 같은 기기 2인.
- **온라인 대국**: 방 코드/링크 초대, 서버가 참가자·차례·합법 수·승패·체스 시계(서버 시간)를 검증, 중복·오래된 요청 무시, 새로고침/끊김 후 재접속(세션 토큰), 연결 끊김 120초 후 몰수패, 입력 크기·속도 제한, 이름 정제.
- 게스트 전용(계정 없음). 최근 기록은 브라우저 localStorage(최대 50개)에만 저장.
- 접근성: 키보드(방향키+Enter), 스크린리더 라벨, 색 외 표시, 다크 모드.

## 제한 사항
- **계정/로그인, 서버측 전적·랭킹, 친구, 관전, 퍼즐은 없습니다.** 온라인 방은 서버 메모리에만 있어 서버 재시작 시 사라집니다.
- 온라인 대국에서는 되돌리기·재대결 없음(새 방 생성).
- 실제 갤럭시 Z 폴드 기기와 "Fold 8 Ultra" 정확한 해상도로는 테스트하지 못했습니다. CSS 폭 360(커버)·780×700(펼침)·600×900 에뮬레이션(Chromium, 터치/모바일 모드)으로만 검증했고, 반접힘(Flex) 자세용 CSS는 넣었지만 미검증입니다.
- 이미지 생성 도구는 쓰지 않았습니다(로고 SVG/PNG는 직접 제작, 기물은 유니코드 글리프).
- ESLint 미설정. 체스 시계/승격 UI의 자동화된 브라우저 테스트는 없습니다(규칙·서버 시계는 단위 테스트).
