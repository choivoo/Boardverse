# Boardverse 1.0 (release candidate)

체스·오목을 중심으로 한 보드게임 플랫폼. 한 개의 Node 서버가 정적 웹앱(React + TypeScript + Vite, PWA), REST API, WebSocket 대국 서버, SQLite DB를 모두 제공합니다. **아직 어디에도 배포되지 않았습니다.**

## 실행
```
npm install
npm run serve          # 빌드 후 서버 실행 → http://localhost:8787  (PORT, DATABASE_PATH 환경변수는 .env.example 참고)
npm run dev            # 클라이언트 개발 서버(5173, /ws 는 8787로 프록시). 다른 터미널에서 npm start
npm test               # vitest (규칙, 서버, 스토어, 퍼즐)
npm run build          # tsc 타입 검사 + vite 빌드
DATABASE_PATH=:memory: npm run serve & node scripts/e2e.mjs   # 모바일 E2E (Chromium 필요, 처음엔 반드시 일회용 DB로)
npx tsx scripts/genPuzzles.ts   # 퍼즐 재생성(시드 고정, 결과는 src/puzzleData.ts)
```
Node 22.5+ 필요 (내장 `node:sqlite` 사용, 실험적 기능 경고가 나올 수 있음).
Docker: `docker build -t boardverse . && docker run -p 8787:8787 -v bv-data:/data boardverse` (**/data 볼륨이 없으면 재시작 시 계정·레이팅이 사라집니다**).

## 기능 (구현·검증된 것만)
- **대국**: 체스(chess.js, BSD-2: 캐슬링·앙파상·승격·체크메이트/스테일메이트·3회 반복·50수·기물 부족, 시계, 무제한/5/10/15+10), 오목(자체 엔진, 13/15/19, 프리스타일 5목 이상·금수 없음). 컴퓨터(초급/보통/어려움: 약한 휴리스틱 봇, 인터넷 없이 브라우저에서 실행, 힌트·되돌리기), 같은 기기 2인.
- **온라인**: 방 코드/링크, 공개 빠른 매칭(게임·시간·판 크기·평가 여부 일치, 평가는 ±400), 서버가 좌석·차례·합법 수·시계(서버 시간)·승패 판정, 중복/오래된 요청 무시, 재접속, 120초 끊김 몰수패, 무승부 제안, 재대결, 친구 초대(WebSocket 푸시).
- **계정(이메일+비밀번호, scrypt, HttpOnly 세션 쿠키)**: 가입/로그인/로그아웃, 비공개 설정, 데이터 내보내기, 계정 삭제(대국은 익명화).
- **레이팅/랭킹**: 로그인한 두 사람의 평가 대국만 Elo 반영(시작 1200, 20판 미만 K=40 이후 20), 게임 종류별 분리(시간 설정별 분리는 없음), 게스트·컴퓨터·친선·2수 미만 대국 제외, 중복 기록 방지, 랭킹 페이지네이션·내 순위. 결과 화면에 변동 표시.
- **시즌**: 데이터 정의(`src/seasons.ts`, UTC), 서버 집계, 보상 1회 수령(중복 방지), 종료 후 TOP10 스냅샷(`finalizeSeasons`, 서버 tick에서 자동 실행). 보상은 코인·코스메틱만.
- **상점/보관함**: 보드 테마·체스 말 세트·오목 돌·프로필 테두리, 미리보기/구매/장착, 코인은 사람과의 대국(6수 이상)에서 서버가 지급(일 100 상한). 코스메틱은 규칙과 무관, 현금 결제·뽑기 없음. 서버가 가격·보유·중복 검증.
- **학습**: 직접 생성·검증한 퍼즐(체스 메이트 1·2수 12개, 오목 승리/방어 16개), 오늘의 문제(UTC 날짜 결정적), 연속일 수(이 기기에만 저장), 복기 뷰어(로컬·서버 기록), 체스 PGN 내보내기/가져오기(검증). 엔진 평가·오프닝 탐색기는 없음(단순 기보 뷰어).
- **친구/안전**: 친구 요청·수락·삭제, 온라인 표시, 차단(매칭·방 입장·초대·친구 요청에서 실제 제외), 신고(관리자 화면 없이 DB `reports` 테이블에 저장, 하루 10건 제한).
- **모바일/폴더블 우선 UI**(커버 ~360px, 펼침 ~780×700 에뮬레이션), 하단 탭, 터치 오목 "탭→확정", PWA 설치·오프라인 로컬 플레이, 접근성(키보드·라벨·색 외 표시), 다크 모드.

## 정책 요약
- 연결 끊김: 120초 안에 같은 기기에서 돌아오면 이어서 진행, 넘으면 몰수패. 시간 초과·기권·몰수는 모두 결과로 기록. 서버 프로세스가 재시작되면 진행 중인 방은 사라지고(DB에는 끝난 대국만 저장) 기록되지 않습니다.
- 게스트끼리의 대국은 서버에 저장하지 않습니다. 코인 농사 방지: 사람과 6수 이상, 일일 상한. 합의 레이팅 조작(두 계정 담합)은 막지 못합니다 — 신고 테이블만 있고 처리 UI는 없습니다.

## 제한 사항 / 미구현 (정직한 목록)
- **미배포.** 실제 운영하려면 HTTPS 뒤의 단일 Node 인스턴스(방이 메모리, 다중 인스턴스 불가) + 영속 볼륨이 필요. 이메일 인증·비밀번호 재설정은 없음(메일 서비스 없음).
- **미구현**: 토너먼트, 클럽, 관전, 게임 중 채팅, 체스 변형(Chess960 등), 렌주 금수, 오프닝 탐색기, 엔진 분석, 운영자(신고 처리) 화면, 시간 설정별 분리 레이팅, 상점에 현금 결제(의도적으로 없음).
- 봇은 약합니다(Stockfish 등 외부 엔진 미포함). 힌트도 같은 봇이 제안합니다.
- 실제 갤럭시 Z 폴드 기기 테스트 없음(Chromium 모바일 에뮬레이션만). 반접힘(Flex) CSS는 미검증. ESLint 미설정.
- 이미지: 이미지 생성 도구(codex CLI)가 이 환경에 없어 모든 자산을 직접 SVG로 제작(워드마크, 카드 일러스트, 기물 세트, PWA 아이콘).
- 퍼즐 진행·연속일·최근 기록은 서버에 동기화되지 않고 브라우저에만 저장됩니다.
